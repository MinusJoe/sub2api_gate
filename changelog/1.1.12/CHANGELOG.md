# 1.1.12

## 更新内容

- 同步 Wei-Shaw/sub2api 0.2.19（`a9240d5016c226b341242a8c54a01a8605cbbc72`），包含管理员 API Key 范围授权、按图片张数计费、Grok 模型目录诊断，以及供应商转发和计费修复。
- 移除 IP 定时测速及使用记录中的代理延迟轮替条，保留手动测试连接。
- 使用记录及错误请求支持拖拽或箭头调整列顺序，独立保存显隐与排序，并可恢复默认顺序。
- Codex 打票代理池仅在系统设置的“Codex 打票”开关开启时显示，关闭后保留已保存的代理池配置。
- 操作日志菜单默认隐藏，可在“系统设置 → 功能开关 → 侧栏菜单”中开启；日志记录功能保持启用。
- 保留原有 Kimi Code OAuth 自动协议转发、Token 刷新和账号定制逻辑。
- Kimi OAuth 支持同步 Kimi 官方上游模型与账号模型映射，查询时刷新令牌并使用账号代理；修复模型列表和映射预设误用 Claude 的问题。
- Claude OAuth / Setup Token 支持独立的上游模型同步与模型映射，映射同时应用于 Messages、Responses、Chat Completions 和 token 计数。Kimi 与 Claude 的模型目录、凭据和配置相互独立。

## 升级说明

- 本版本包含上游数据库迁移 247、248，启动时自动执行。
- 现有账号、菜单显隐、计费和代理配置继续保留；未配置的操作日志菜单默认隐藏。
- 本次为 2026-10-29 的同版本重建，版本号仍为 1.1.12；已有安装需要重新拉取镜像并重建容器，或重新下载安装包，才能使用本次修复。
- OAuth 账号完成授权并保存后，可在“编辑账号 → 模型限制 → 模型白名单”同步上游模型，再保存配置。项目 API Key 的模型列表按绑定分组和模型白名单返回。
- 仓库已更名为 `MinusJoe/sub2api_gate`，发布镜像为 `ghcr.io/minusjoe/sub2api_gate:1.1.12`；安装脚本和更新源已同步调整。提供 Linux amd64/arm64、macOS amd64/arm64 和 Windows amd64 安装包及 SHA-256 校验文件。
