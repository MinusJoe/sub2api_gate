# 1.1.12

## 更新内容

- 同步 Wei-Shaw/sub2api 0.2.19（`a9240d5016c226b341242a8c54a01a8605cbbc72`），包含管理员 API Key 范围授权、按图片张数计费、Grok 模型目录诊断，以及供应商转发和计费修复。
- IP 管理新增定时测速：1、3、5、10、30、60 秒和自定义间隔，最低 1 秒；支持选中 IP 或当前筛选范围，避免慢请求重叠，离开页面或关闭浏览器时停止。
- 使用记录及错误请求支持拖拽或箭头调整列顺序，独立保存显隐与排序，并可恢复默认顺序。
- 管理端使用记录显示已设置自动测速的代理：每组最多两个，超过两个每 5 秒轮替，支持暂停、手动切换，并显示最近测速的延迟、状态和时间。
- 操作日志菜单默认隐藏，可在“系统设置 → 功能开关 → 侧栏菜单”中开启；日志记录功能保持启用。
- 保留原有 Kimi Code OAuth 自动协议转发、Token 刷新和账号定制逻辑。

## 升级说明

- 本版本包含上游数据库迁移 247、248，启动时自动执行。
- 现有账号、菜单显隐、计费和代理配置继续保留；未配置的操作日志菜单默认隐藏。
- 自动测速只在浏览器的 IP 管理页面运行；使用记录中的代理条展示这些 IP 的最近测速结果。
- 发布镜像为 `ghcr.io/talent668/sub2api_gate:1.1.12`，提供 Linux amd64/arm64、macOS amd64/arm64 和 Windows amd64 安装包及 SHA-256 校验文件。
